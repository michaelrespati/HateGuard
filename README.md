# HateGuard: Hate Speech Detection Model
This repository contains the source code and dataset used in the research paper “Hate Speech Detection Using the High-Accuracy Deep Learning-Based HateGuard Model.”
## Description
This code is a Jupyter Notebook (Google Colab) that covers the text preprocessing, deep learning model training, and performance evaluation of the HateGuard model in detecting hate speech. Additionally, there is a UI application for testing the trained hate speech detection system.
## How to Use
To run this code:
1. Download the HateGuard_Training.ipynb and HateGuard_App.ipynb files.
2. Run all cells in HateGuard_Training until the training process is complete. Allow Colab to access your Drive to save the model.
3. If prompted to enter an API key, open Google AI Studio, copy the API key, and paste it into the “value” field under “secrets” in Colab. Use the name specified in the code. Then enable notebook access.
4. Run the code until it finishes; only then will you be able to access HateGuard_App using the model saved to your Drive.
